🚀 PASOS PARA IMPLEMENTAR
═══════════════════════════════════════════════════════════════════════════

1. CONFIGURAR VARIABLES DE ENTORNO:
   $ cp .env.example .env
   $ nano .env  # Llenar CODA_API_KEY, GEMINI_API_KEY, ALLOWED_ORIGINS

2. INSTALAR DEPENDENCIAS:
   $ python3 -m venv venv
   $ source venv/bin/activate
   $ pip install -r requirements.txt

3. CAMBIAR CREDENCIALES ADMIN:
   $ python3
   >>> from server import hash_password_pbkdf2
   >>> salt, pwd_hash = hash_password_pbkdf2("mi_nueva_contraseña")
   >>> # Actualizar dashboard_auth.json

4. EJECUTAR SERVIDOR:
   $ python3 server.py
   # Navegador a: http://localhost:5000

5. VALIDAR SEGURIDAD:
   $ python3 test_security.py
